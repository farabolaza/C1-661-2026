TP 05

Linealización de datos, Solver y gráficas.

1 Linealización de datos

1.1 Caída libre con resistencia

Un modelo posible para la velocidad de caída de un cuerpo que experimenta resistencia con el aire puede ser :

\[ v(t)=v_t \left(1-e^{kt} \right) \]

Donde \(v_t\) es la velocidad terminal del cuerpo (sumna de fuerzas igual a cero)

  1. Importar los datos de este archivo a calc
  2. Graficar los datos originales
  3. Linealizar el modelo
  4. Obtener el valor de \(k\) y el modelo físico resultante.

RTA: \(k=0,2\), \(v(t)=50\cdot (1-e^{-0,2t})\)

1.2 Ley de enfriamiento de Newton

Según la ley de enfriamiento de un cuerpo de Newton, la temperatura de un cuerpo en un entorno viene dada por el siguiente modelo: \[ T(t) = T_{\text{amb}} + (T_0 - T_{\text{amb}}) e^{-kt} \]

Aplique los conceptos de linealización para ajustar los datos que se le proveen.

  1. Importar los datos de este archivo a calc.
  2. Grafique los datos. Encuentre \(T_0\) y \(T_{\text{amb}}\)
  3. Graficar ln(T - T_amb) vs. tiempo.
  4. Realizar regresión lineal para obtener \(k\).

RTA: \(T_0=80\), \(T_{\text{amb}}=20\), \(K=0,1\)

1.3 Posición de un cuerpo con rozamiento viscoso

Para determinado movimiento, se supone que el modelo que lo representa esta dado por: \[ x(t)=x_0 \cdot e^{-bt} \]

LibreOffice Calc:

  1. Importar los datos de este archivo a calc
  2. Grafique los datos
  3. Linealizar le modelo
  4. Graficar y realizar regresión lineal para obtener \(b\).
  5. Escriba la ecuación con los parámetros de los datos

RTA: \(x_0=10\), \(b=0,3\)

1.4 Decaimiento Radioactivo

El número de partículas de cierto isótopo que se desintegra por emisión radioactiva se supone modelado por la siguiente expesión:

\[ N(t) = N_0 e^{-\lambda t} \]

Donde \(N_0\) es la cantidad de particulas iniciales y \(\lambda\) la constante de desintegración.

  1. Importar los datos de este archivo a calc
  2. Graficar los datos.
  3. Linealizar el modelo.
  4. Graficar los datos linealizados
  5. Encuentre \(\lambda\) y escriba la ecuación para los datos.

RTA: \(N_0=500\), \(\lambda = 0,05\)

2 Solver

  1. Usar los archivos del punto anterior y obtener el la ecuación ajustando con solver
  2. Graficar en un mismo lienzo (gráfico) los datos experimentales y la ecuación del ajuste
